# Security Policy

## Supported Versions

The following versions of the project are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please open a GitHub Issue with the "security" label. Alternatively, you can contact the lead architect directly via GitHub.

We appreciate your help in keeping this project secure for the mental health tech community.
